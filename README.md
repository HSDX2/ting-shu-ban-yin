# 听书伴音（Audiobook BGM）

为「番茄小说」等听书场景提供**背景音乐**的手机 App：一边听书一边放背景音乐，蓝牙耳机按一下，听书和背景音乐一起暂停/恢复，背景音乐音量独立可调。

纯应用方案，无需 root。若在特定 ROM 上被系统策略干扰，可用 LSPosed 模块兜底（见文末）。

## 核心原理

| 需求 | 实现 |
| --- | --- |
| 两路音频同时播放 | 背景音乐用 ExoPlayer 播放，初始化时 `handleAudioFocus=false`，**从不申请音频焦点、不注册焦点监听**。Android 音频焦点是"自愿参与"机制，番茄小说抢焦点时没有任何回调打到本应用，两路音频在系统混音器里自然共存 |
| 蓝牙耳机一键同停/同播 | 耳机按键派发给"当前持有焦点的 MediaSession"＝番茄小说 → 它暂停。本应用通过**通知使用权**观察所有会话，注册 `PlaybackState` 回调，一旦其他应用进入播放/暂停就镜像控制背景音乐（含切歌/快进防抖，不会抖） |
| 不抢耳机按键 | 本应用**不创建 MediaSession**，因此系统始终把耳机按键路由给听书 App；听书停/播后，本应用再跟随 |
| 音量独立可调 | 播放器自带增益 `setVolume(0..1)` 只调背景音乐；系统音量键调混音总音量 |
| 后台不被杀 | `mediaPlayback` 类型前台服务 + 常驻通知（通知内可直接调音量、播放/暂停） |

> ⚠️ **必须授予「通知使用权」**：Android 不允许普通应用直接读取别的应用的媒体会话，只有成为"通知监听器"才被允许。App 内点「开启通知使用权」跳转系统设置，打开「听书伴音」的开关即可；否则无法自动跟随（但不会崩溃）。

同步行为：**全自动镜像** —— 检测到任一其他应用开始播放 → 背景音乐自动开播；其暂停 → 背景音乐跟停；其恢复 → 背景音乐自动恢复。支持白名单限定只跟随指定应用。

## 安装

1. 将 `app-debug.apk`（或 release 包）传到手机安装。
2. 首次打开：允许通知权限。
3. 点「开启通知使用权」→ 在系统设置里打开「听书伴音」开关（**必做**，否则无法跟随）。
4. 点「选择文件夹」选一个放背景音乐的文件夹（可用系统文件管理器授权整个目录，后续递归扫描子目录里的音频文件，支持 mp3/flac/wav/m4a/ogg 等）。
5. 拖动音量滑块调背景音乐音量（独立）。
6. 服务会自动启动；也可手动点「启动服务」。

## 一加13（ColorOS）后台设置（重要）

ColorOS 会主动清理后台，请务必设置（App 内也有「后台保活设置」和「开机自启动」入口）：

1. 桌面长按 App 图标 → 应用信息 → **允许自启动**（打开）。
2. App 内点「后台保活设置」→ **电池优化 → 选择「听书伴音」→ 不优化**（或 设置 → 电池 → 应用省电 → 不限制）。
3. 应用信息 → 耗电管理 → **允许后台运行**；关闭「深度清理/纯净后台」对该 App 的限制。
4. **最近任务里把 App 卡片下拉/点锁**，锁定后不会被杀。
5. 通知使用权（跟随同步必需）、通知权限（前台服务通知）都打开。

> App 已内置加固：前台服务 `START_STICKY`（被系统杀掉会自动重启）+ **从最近任务划掉 App 会自动重启服务恢复通知** + 开机自启接收器。但仍需以上系统设置配合，ColorOS 才能彻底放行后台。

## 可行性验证步骤（手机实测）

1. **共存**：App 里点「启动服务」并开始放背景音乐 → 再打开番茄小说播放听书 → 确认两个声音**同时**从耳机出来。
2. **同步**：按蓝牙耳机播放/暂停键 → 番茄小说暂停，背景音乐**跟着**暂停；再按 → 一起恢复。
3. **音量**：App 滑块调背景音乐音量，确认听书音量不受影响；音量键确认只当总音量用。
4. **后台**：熄屏、切到桌面、开别的 App，确认背景音乐一直在，不被杀。
5. **通知栏**：下拉通知，用「音量 +/−」和「播放/暂停」直接操作背景音乐。

## 常见问题

- **只听到一路声音**：确认番茄小说播放的同时本 App 状态栏显示「跟随……播放中」；若没显示，可能是该听书 App 没暴露 MediaSession（少见）。
- **耳机按键只控制背景音乐、听书没反应**：说明系统把按键派发给了本应用而非听书 App。这是各 ROM 媒体键路由差异，先用通知栏/手机验证同步逻辑是否正常；若确认是路由问题，见下方 Plan B。
- **开机后服务没起来**：确认「开机自动启动服务」开关打开，且已在 ColorOS 允许自启动。

## Plan B（root + LSPosed 增强，可选）

若纯应用方案在实测中不稳定（共存被系统策略干扰 / 媒体键路由异常），再做 LSPosed 模块：

- 全局忽略音频焦点：Hook `AudioService.requestAudioFocus`，让系统永远不强制暂停本应用；
- 或直接 Hook 番茄小说的播放/暂停方法，把"播放状态"信号可靠地暴露给本应用。
